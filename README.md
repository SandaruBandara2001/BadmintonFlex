# BadmintonFlex 🏸

Computer-vision–assisted **badminton training** web app built with **Python + Flask** and a simple HTML/CSS frontend.  
It serves pages from `templates/`, static assets from `static/`, and loads pre-trained model artifacts (`.pkl` / `.keras`) for pose/skill analysis.

---

## ✨ Features
- Web UI with multiple pages (Home, Demo, Live Session, Profile, Login)
- Loads ML artifacts (pickled models & optional Keras model) for predictions
- Static assets for drills/demos
- MIT-licensed

---

## 🧰 Tech Stack
- **Backend:** Python, Flask
- **Frontend:**  Bootstrap, HTML, CSS
- **Models:** `*.pkl`, `*.keras`
- **DevOps:** Git LFS for large files
